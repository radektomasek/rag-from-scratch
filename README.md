# RAG from scratch

A set of patterns showcasing principles behind building RAG pipelines. A Boot.dev workshop.

This repository contains several scripts, that demonstrate the following:

- keyword search using standard inverted index (for each document calculate the frequency of keywords).
- keyword search using BM25.
- semantic search using cosinus similarity.
- hybrid search combining both approaches and build a rank system.

These approaches are used for a RAG pipeline and some reranking is involved.
